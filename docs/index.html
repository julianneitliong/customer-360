Loopwise Customer 360: an AI analyst on clean, modeled data

Loopwise is a fictional B2B SaaS company whose customer data was split across a CRM, a billing tool and product-usage exports. I ingested all three into AWS, cleaned and matched them with dbt, and documented every column, so an AI model can answer business questions accurately.

Below, Claude on Amazon Bedrock reads the dbt data dictionary, writes the SQL for each question, and explains the result. Every query is checked to be read-only before it runs on Athena.
